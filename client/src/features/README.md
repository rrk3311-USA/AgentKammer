# Features

Feature folders are for product domains that combine UI, data, questions, recommendations, and route-level behavior.

Initial target areas:

- `decision-briefs`
- `decision-navigator`
- `building-intelligence`
- `building-reports`
- `neighborhoods`
- `diagnostics`
- `recommendations`
- `search`
- `onboarding`

Existing route files still live in `client/src/pages`. Migrate a page into `features` only when the feature is actively being changed and the import path can be verified.
