1. Operating model

Three layers stay separate on purpose:

Website

Decision Guide + Hub. Captures light profile data and intent. Clients never see Attio or lead scores.

Admin companion

/admin — monitor charts, conversations, stage, and force Attio resync. Not the system of record for tasks.

Attio

Internal CRM of record: People, Housing Advisory charts, lists, tasks, and Transactions when a real deal starts.

Sync rule

Chat is never blocked on Attio. Profile changes queue async. Use Resync Attio after manual stage changes.

2. People · Housing · Deals

People — identity & ops only

  • Native contact fields (name, email, phone)
  • Visitor ID, Lead source, Lifecycle stage, Lead score
  • Timeline, Assigned advisor, Last active, Next action
  • Attio sync status

Do not store the full housing profile on People.

Housing Advisory — longitudinal chart

  • Situation, desired outcome, current housing
  • Locations, budget, timeline
  • Financing / credit / down-payment readiness
  • Constraints, trade-offs, dealbreakers
  • Readiness & belonging scores
  • Advisor summary, next recommendation, next review, membership status

Transactions — real execution only

Create a Transaction when purchase, sale, lease, or buy-sell execution begins — not while someone is still planning. Put open deals on Active Transactions. Link Client → People and optionally Housing chart.

Closing a deal does not make the Person Inactive. Move them to Advisory Client unless the relationship has truly ended.

3. Canonical lifecycle

One vocabulary everywhere: website database, admin, Attio People, and list stages.

New Signal Engaged Profiled Qualified Call Ready Long-Term Nurture Advisory Client Transaction Ready Inactive

When to use Inactive

  • Disqualified leads
  • Unresponsive after a defined period
  • Opted out
  • Former clients with no ongoing relationship

Deal stages (Preparing → Closed / Lost) live only on Transactions — never on People lifecycle.

4. Lists & when to use them

Lead Pipeline

Pre-client board: New Signal → Long-Term Nurture. Website sync places leads here.

Current Clients

When lifecycle = Advisory Client (or Transaction Ready / Inactive). Automation moves them off Lead Pipeline.

Active Transactions

Open deal files only. Stay empty during pure advisory / planning.

Admin actions

Mark Advisory Client in /admin/clients, then Resync Attio to refresh lists.

5. Daily workflow

  1. Scan Overview for Call Ready and high-intent signals.
  2. Open the client in Clients — read AI summary + chart fields.
  3. Work the relationship in Attio (notes, tasks, list stage).
  4. If you change stage in admin, click Resync Attio.
  5. When execution starts, create a Transaction and add it to Active Transactions.
  6. After close, keep Person as Advisory Client unless the relationship ends → then Inactive.

6. First-day verification

Confirm the model is live in your workspace:

  1. Open a lead in /admin/clients
  2. Change lifecycle to Advisory Client
  3. Trigger Resync Attio
  4. Person leaves Lead Pipeline
  5. Person appears on Current Clients
  6. List stage = Advisory Client
  7. Housing data remains on the linked Housing Advisory record
  8. No deal appears on Active Transactions
Start verification in admin

7. What not to do

  • Don’t invent parallel stage labels (“Exploring”, “Ready Soon”) in Attio or admin.
  • Don’t dump the housing chart onto the People record.
  • Don’t create Transactions for planning-only clients.
  • Don’t mark Inactive just because a deal closed.
  • Don’t expect every chat turn to sync — summaries and stage/profile changes do.
