Not a generic contact inbox as the system of record.

Required form promise

Shown on the form and on the confirmation screen. Country pages localize this sentence.

Page system

Every country page uses the same order: Hero → Intro → FAQ → Neighborhoods → Process → Mistakes → Professional team → Resources → Strategy form.

Add new countries via COUNTRY_SEEDS / buildCountry() in client/src/data/international-hub.ts — do not invent a new layout.

Ops follow-up

  1. Email arrives with preferred language + status in the subject.
  2. Assign someone who can speak that language (or a trusted bilingual partner).
  3. Production also upserts Attio People + Housing Advisory + Lead Pipeline when keys are set.
  4. Recommend Housing Strategy Session / membership only when appropriate — see Practice guide.
