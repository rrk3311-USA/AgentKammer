# Agent Kammer Phase 2B Content Consolidation

## Objective

Reduce repetition across Home, Buildings, Intelligence, Strategy, and Buy / Sell.

## Page Ownership

### Home

Primary question: what is Agent Kammer?

Home now introduces the brand, shows the three core pillars, explains the building-first idea briefly, previews buildings, and moves users toward `Curate Matches`.

### Buildings

Primary question: which buildings should I consider?

`/buildings` now owns the curated watchlist, building profiles, amenities, resident experience, and neighborhood placement.

### Intelligence

Primary question: what research is produced?

`/real-estate` now focuses on research deliverables: Building Intelligence Reports, Comparable Analysis, Neighborhood Reports, Opportunity Monitor, and Market Outlook.

### Strategy

Primary question: why is Agent Kammer different?

`/strategy` owns the methodology: Strategic Property Acquisition, the four-step framework, Traditional Agent vs Agent Kammer, methodology lenses, and Meet Agent Kammer.

### Buy / Sell

Primary question: how do you help me transact?

`/buy-sell` owns Reverse Buyer Origination, Reverse Seller Architecture, buyer process, seller first-read, offer strategy, and private value assessment. It links to Strategy instead of repeating the philosophy.

## Consolidation Actions

- Added a dedicated `/buildings` route and moved the full building universe there.
- Reduced Home from full building catalog to a featured preview.
- Removed deep methodology from the Intelligence page.
- Removed the Traditional Agent vs Agent Kammer comparison from Buy / Sell.
- Kept the full methodology explanation on Strategy.
- Updated building navigation from `/#buildings` to `/buildings`.

## Rule

If a concept appears on three or more pages, Strategy owns the full explanation and other pages link to it.
