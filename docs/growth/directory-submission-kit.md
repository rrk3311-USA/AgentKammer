## Submission Rules

1. Use the same name, phone, address, website, and category everywhere.
2. Do not expose a raw public email unless the directory requires it.
3. Use `https://www.agentkammer.com/contact#request-call` as the preferred lead destination.
4. Use a niche landing page only when the directory has a services field or profile links field.
5. Avoid low-quality spam directories that publish scraped listings with no moderation.
6. Track every submission with date, login owner, status, profile URL, and follow-up needed.
