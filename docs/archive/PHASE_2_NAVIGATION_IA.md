# Agent Kammer Phase 2 Navigation & Information Architecture

## Objective

Create a site structure that can be understood within 5 seconds.

## Core Positioning

Most agents start with listings.

Agent Kammer starts with the building.

Every page should reinforce this idea.

## Primary Navigation

- Lease
- Buy / Sell
- Buildings
- Intelligence
- Strategy
- Curate Matches

`Intelligence` is the intellectual property section. `Strategy` absorbs the former About page and explains why the methodology is trustworthy.

## Five-Second Test

A new visitor should understand:

1. Manhattan
2. Buildings
3. Leasing
4. Acquisition
5. Intelligence

If a page does not reinforce one of those five concepts, reconsider whether it belongs.

## Page Purposes

### Home

Purpose: explain the philosophy.

Key sections:
- Hero
- Building Fit
- Market Timing
- Deal Leverage
- Why We Start With The Building
- Featured Buildings
- Relocating To Manhattan
- Contact CTA

### Lease

Question: how do I find the right luxury rental?

Content:
- Curated buildings
- Neighborhood guidance
- Building comparison
- Amenity analysis
- Relocation support

CTA: Schedule Consultation

### Buy / Sell

Question: how do I transact with better context?

Content:
- Building intelligence
- Market timing
- Acquisition process
- Buyer representation
- Featured opportunities
- Pricing intelligence
- Market positioning
- Buyer competition
- Preparation strategy

CTA: Start Acquisition Search or Request Property Review

### Buildings

Question: which buildings should I consider?

Content:
- Curated building catalog
- Building profiles
- Amenity comparisons
- Neighborhood comparisons
- Search and filter

This should become the strongest long-term asset.

### Intelligence

Question: what does the market say?

Content:
- Building Fit
- Market Timing
- Deal Leverage
- Neighborhood research
- Market reports
- Guides
- Building analyses

This is the intellectual property section. The page title can remain `Manhattan Intelligence`.

### Strategy

Question: why trust this methodology?

Content:
- Philosophy
- Background
- Process
- Approach
- Brand story
- Traditional Agent vs Agent Kammer
- Meet Agent Kammer

## Remove Or Avoid

- Saved search platform language
- Email digest product language
- Dashboard product language
- Consumer search engine language
- Generic real estate marketing copy

## Narrative Model

Traditional agent:

Properties

Agent Kammer:

Buildings

Properties

The site should keep reinforcing the shift from property-first to building-first.
